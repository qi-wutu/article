## 归档方式

- 每篇文章使用独立文件夹，沿用 `年.月.日-主题` 命名方式。
- 正文使用 Markdown，相关图片和附件放在同一文章文件夹中，使用相对路径引用。
- 新增文章后，在上方目录补充链接。

## 同步到 GitHub

在本目录打开终端，执行：

```sh
git add .
git commit -m "docs: archive new article"
git push
```

保存文件后需要提交并推送，才会同步到 GitHub。
